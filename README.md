# Raisul Karim Saju Portfolio

A modern developer portfolio website built to showcase projects, publications, leadership experience, technical expertise, and professional background.

The portfolio focuses on a clean visual system, reusable architecture, smooth animations, and responsive user experience.

---

## Features

- Modern dark-themed developer portfolio
- Fully responsive across desktop, tablet, and mobile
- Reusable core-component architecture
- Smooth animations and micro-interactions
- Project & publication showcase
- Leadership & volunteering section
- Skills & competencies section
- Experience timeline
- Awards & certifications showcase
- Contact form with EmailJS integration
- Data-driven content structure

---

## 🛠 Tech Stack

### Frontend
- Next.js (App Router)
- React
- TypeScript
- Mantine UI

### Styling & Design
- Custom design tokens
- CSS-in-JS via Mantine
- Grid-based responsive layouts
- Gradient cards and depth effects

### Animations
- Framer Motion
- Hover animations
- Scroll reveal animations
- Interactive flip cards

### Forms & Integrations
- EmailJS
- Environment-based configuration

---
